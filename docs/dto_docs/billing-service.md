## InvoiceDTO

**Direction:** Request / Response  
**Endpoints:** `GET /api/billing/invoices`, `POST /api/billing/invoices`, `PUT /api/billing/invoices/{id}`

| Field | Type | Notes |
|-------|------|-------|
| `invoiceId` | `Long` | Response only — auto-generated primary key |
| `patientId` | `Long` | Required |
| `encounterId` | `Long` | Optional — links invoice to a clinical encounter |
| `appointmentId` | `Long` | Optional — set when invoice originates from an appointment |
| `prescriptionId` | `Long` | Optional — set when invoice originates from a prescription |
| `labOrderId` | `Long` | Optional — set when invoice originates from a lab order |
| `description` | `String` | **Auto-generated server-side** on create/update based on source context (max 500 chars). Not required in request body. |
| `lineItemsJson` | `String` | JSON-encoded list of line items (optional) |
| `subtotal` | `BigDecimal` | Amount before tax and discounts |
| `taxes` | `BigDecimal` | |
| `discounts` | `BigDecimal` | |
| `totalAmount` | `BigDecimal` | Response only — calculated as `subtotal + taxes - discounts` |
| `status` | `String` | `"PENDING"`, `"PAID"`, `"CANCELLED"`, `"UNPAID"` |
| `issuedAt` | `LocalDateTime` | Set by caller if provided; defaults to `now()` if null |

**Description generation logic:**
The `description` field is auto-generated by `BillingService.generateInvoiceDescription()` and reflects the invoice's source context:

| Condition | Generated text |
|-----------|---------------|
| `appointmentId` set | `"Consultation fee for Patient #<id> — Appointment #<id>. Total: $<amount>"` |
| `prescriptionId` set | `"Prescription charge for Patient #<id> — Prescription #<id>. Total: $<amount>"` |
| `labOrderId` set | `"Lab order fee for Patient #<id> — Lab Order #<id>. Total: $<amount>"` |
| `encounterId` set (only) | `"Clinical encounter for Patient #<id> — Encounter #<id>. Total: $<amount>"` |
| None set | `"Medical services for Patient #<id>. Total: $<amount>"` |

Tax/discount suffixes are appended when non-zero.
